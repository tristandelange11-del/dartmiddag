# Dartmiddag

Website voor een dartmiddag met 6 vrienden: oefenbord, huisregels en een live spel waarbij de laagste score het eerste rondje betaalt.

- `project/Main.dc.html`: homepage met uitnodiging, oefenbord en huisregels
- `aanwezigheid.html`: live spel (naam kiezen, aanwezig of afwezig, één pijl gooien)
- `md/ontwerp.md`: ontwerpnotities
- `memory/gegevens.md`: datum, tijd, locatie en spelers
